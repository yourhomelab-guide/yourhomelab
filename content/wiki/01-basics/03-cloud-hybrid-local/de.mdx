## Die drei Modelle

<Cards>
  <Card title="Lokal">
    Der Server steht bei dir zuhause, etwa ein Mini-PC oder ein altes Notebook. Deine Daten verlassen das Haus nicht.
  </Card>
  <Card title="Hybrid">
    Die Daten liegen zuhause, ein kleiner Cloud-Server oder ein Tunnel nimmt die Anfragen aus dem Internet entgegen.
  </Card>
  <Card title="Cloud">
    Du mietest einen virtuellen Server (VPS) in einem Rechenzentrum. Feste IP, kein Gerät zuhause, monatliche Kosten.
  </Card>
</Cards>

## Im Vergleich

|                 | Lokal                            | Hybrid                                 | Cloud                          |
| --------------- | -------------------------------- | -------------------------------------- | ------------------------------ |
| **Kosten**      | Hardware einmalig, danach Strom  | Hardware plus kleiner VPS              | Monatliche Miete               |
| **Datenhoheit** | Vollständig bei dir              | Daten zuhause, Eingang beim Anbieter   | Beim Anbieter                  |
| **Erreichbarkeit** | Hängt vom Anschluss ab        | Gut, auch ohne öffentliche IPv4        | Sehr gut, feste IP             |
| **Aufwand**     | Mittel                           | Höher, zwei Systeme                    | Gering                         |
| **Gut für**     | Fotos, Medien, große Datenmengen | Öffentliche Dienste mit Daten zuhause  | Kleine Dienste, erster Einstieg |
