## Zwei Fragen vorab

Bevor du dich für einen Weg entscheidest, kläre zwei Dinge:

1. **Wer soll zugreifen?** Nur du und deine Familie, oder auch andere Menschen, die einfach einen Link im Browser öffnen?
2. **Was kann dein Anschluss?** Hast du eine eigene öffentliche IPv4-Adresse, oder sitzt du hinter [CGNAT oder DS-Lite](/de/nachschlagen/cgnat-ds-lite/)? Ohne öffentliche IPv4 kommen Anfragen von außen nicht bis zu deinem Router.

Die erste Frage entscheidet zwischen **privat** (VPN) und **öffentlich** (Portfreigabe, Tunnel, VPS). Die zweite entscheidet, welche öffentlichen Wege überhaupt funktionieren.

## Die Wege im Überblick

<Cards>
  <Card title="Portfreigabe">
    Der Router leitet Port 80 und 443 an deinen Reverse Proxy weiter. Direkt und ohne Dritte, braucht aber eine öffentliche IPv4.
  </Card>
  <Card title="VPN">
    Deine Geräte verbinden sich verschlüsselt mit dem Heimnetz. Nichts ist öffentlich, nur du kommst rein.
  </Card>
  <Card title="Tunnel">
    Dein Server verbindet sich nach außen zu einem Anbieter wie Cloudflare, der die Anfragen durchreicht. Kein offener Port nötig.
  </Card>
  <Card title="Eigener VPS">
    Ein gemieteter Server mit fester IP ist dein öffentlicher Eingang, per WireGuard mit dem Heimserver verbunden.
  </Card>
</Cards>

## Im Vergleich

|                    | Portfreigabe                   | VPN (WireGuard, Tailscale)          | Tunnel (Cloudflare)              | Eigener VPS (WireGuard, Pangolin)  |
| ------------------ | ------------------------------ | ----------------------------------- | -------------------------------- | ---------------------------------- |
| **Wer kommt rein** | Alle                           | Nur deine Geräte                    | Alle                             | Alle                               |
| **Sicherheit**     | Mittel, alles hängt am Proxy und an den Diensten | Hoch, nichts ist öffentlich | Mittel, Heim-IP bleibt verborgen | Mittel, Heim-IP bleibt verborgen   |
| **Aufwand**        | Gering                         | Gering (Tailscale) bis mittel (WireGuard) | Gering                      | Hoch, zweiter Server               |
| **CGNAT-tauglich** | Nein                           | Tailscale ja, WireGuard selbst nein | Ja                               | Ja                                 |
| **Abhängigkeit**   | Keine                          | Keine (WireGuard) bzw. Anbieter (Tailscale) | Cloudflare               | VPS-Anbieter                       |
| **Für wen**        | Öffentliche IPv4, Dienste für andere | Admin-Zugriff, Dienste nur für dich | CGNAT, schneller Start      | CGNAT, volle Kontrolle             |

Ein paar Anmerkungen zur Tabelle:

- **Sicherheit** meint hier, wie viel von außen sichtbar ist. Portfreigabe, Tunnel und VPS machen deine Dienste gleichermaßen öffentlich. Wie sicher das ist, entscheiden dein Reverse Proxy, Login-Schutz und aktuelle Updates.
- **WireGuard selbst** braucht eine Portfreigabe für einen UDP-Port und damit ebenfalls eine öffentliche IPv4 oder funktionierendes IPv6.
- **Cloudflare Tunnel** ist ungeeignet für große Uploads und Medien-Streaming. Details stehen unter [Tunnel](/de/nachschlagen/tunnel/).

## Die übliche Kombination

Die meisten Homelabs nutzen nicht nur einen Weg:

- **Admin-Oberflächen und SSH nur über VPN.** Portainer, Router, Proxmox und Co. sind nie öffentlich.
- **Dienste für andere über Portfreigabe, Tunnel oder VPS.** Etwa eine Nextcloud zum Teilen oder Vaultwarden für die Familie, geschützt durch Reverse Proxy und Login.
- **Alles andere bleibt im Heimnetz.** Nicht jeder Dienst muss von außen erreichbar sein.
