level: 2

<Callout title="Traefik oder Nginx Proxy Manager?">
Traefik ist am Anfang etwas komplizierter, bietet dafür am meisten Möglichkeiten: Die Konfiguration steht als Labels direkt in der `compose.yaml` jedes Dienstes, Middlewares wie Login-Schutz schaltest du per Label davor, und alles lässt sich als Datei versionieren. Wer es erst mal einfach will, nimmt [Nginx Proxy Manager](/de/einrichten/reverse-proxy-npm/) mit Weboberfläche.
</Callout>

<Steps>

<Step title="Proxy-Netzwerk anlegen">
Alle Dienste, die Traefik erreichen soll, hängen in einem gemeinsamen Docker-Netzwerk. Du legst es einmal an und referenzierst es danach in jedem Stack.

```bash
docker network create __NETWORK__
```
</Step>

<Step title="Verzeichnis anlegen">
Jeder Stack bekommt einen eigenen Ordner unter `__ROOT__`. Die persistenten Daten von Traefik, also die Zertifikate, liegen in `__DATA(traefik)__`.

```bash
mkdir -p __ROOT__/traefik __DATA(traefik)__/letsencrypt
touch __DATA(traefik)__/letsencrypt/acme.json
chmod 600 __DATA(traefik)__/letsencrypt/acme.json
```
</Step>

<Step title="compose.yaml und .env schreiben">
Die Konfiguration steht in `compose.yaml`. Werte, die sich zwischen Servern unterscheiden, kommen in die `.env`.

<ServiceFiles id="traefik" />
</Step>

<Step title="Starten und prüfen">
Beim ersten Start holt Traefik das Zertifikat. Im Log siehst du, ob die TLS-Challenge durchgeht.

```bash
cd __ROOT__/traefik
docker compose up -d
docker compose logs -f traefik
```

Meldet das Log Fehler bei der Challenge oder zeigt der Browser das Standardzertifikat von Traefik, hilft [Zertifikat fehlt](/de/nachschlagen/zertifikat-fehlt/) weiter.
</Step>

<Step title="Ersten Dienst anbinden">
Ein Container wird über Labels an Traefik gehängt. Danach ist er unter seiner Subdomain mit gültigem Zertifikat erreichbar.

```yaml
labels:
  - traefik.enable=true
  - traefik.http.routers.whoami.rule=Host(`whoami.__DOMAIN__`)
  - traefik.http.routers.whoami.tls.certresolver=le
```

Antwortet die Subdomain mit „Bad Gateway“, erreicht Traefik den Container nicht. Die üblichen Ursachen stehen unter [Bad Gateway](/de/nachschlagen/bad-gateway/).

<Callout title="Eigene Dienste anbinden">
Für Dienste aus dem [Katalog](/de/dienste/) setzt „Mein Setup“ die Labels automatisch. Für alles andere erzeugt das Werkzeug [Proxy-Konfiguration](/de/werkzeuge/proxy-konfiguration/) die passenden Labels aus Subdomain, Containername und Port.
</Callout>
</Step>

</Steps>
