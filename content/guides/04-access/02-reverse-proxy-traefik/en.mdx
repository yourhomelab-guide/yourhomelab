<Callout title="Traefik or Nginx Proxy Manager?">
Traefik is a bit more complicated at first, but it offers the most options: The configuration is stored as labels directly within each`compose.yaml` service; you can enable middleware such as login protection by adding a label before it; and everything can be versioned as a file. If you want to keep things simple at first, use [Nginx Proxy Manager](/en/setup/reverse-proxy-npm/) with its web interface.
</Callout>

<Steps>

<Step title="Create a proxy network">
All services that Traefik is supposed to reach are connected via a shared Docker network. You create it once and then reference it in each stack.

```bash
docker network create __NETWORK__
```
</Step>

<Step title="Create a directory">
Each stack gets its own folder under `__ROOT__`. Traefik's persistent data—that is, the certificates—is stored in `__DATA(traefik)__`.

```bash
mkdir -p __ROOT__/traefik __DATA(traefik)__/letsencrypt
touch __DATA(traefik)__/letsencrypt/acme.json
chmod 600 __DATA(traefik)__/letsencrypt/acme.json
```
</Step>

<Step title="Write `compose.yaml` and `.env`">
The configuration is located in `compose.yaml`. Values that differ between servers are specified in the `.env`.

<ServiceFiles id="traefik" />
</Step>

<Step title="Start and Check">
When Traefik starts up for the first time, it retrieves the certificate. You can see in the log whether the TLS challenge is successful.

```bash
cd __ROOT__/traefik
docker compose up -d
docker compose logs -f traefik
```

If the log reports errors during the challenge or if the browser displays Traefik's default certificate, see "[Certificate Missing"](/en/wiki/certificate/) for further assistance.
</Step>

<Step title="Connect the first service">
A container is attached to Traefik via labels. It can then be accessed at its subdomain with a valid certificate.

```yaml
labels:
  - traefik.enable=true
  - traefik.http.routers.whoami.rule=Host(`whoami.__DOMAIN__`)
  - traefik.http.routers.whoami.tls.certresolver=le
```

If the subdomain returns a "Bad Gateway" response, Traefik cannot reach the container. The common causes are listed under "[Bad Gateway](/en/wiki/bad-gateway/)."

<Callout title="Integrate Your Own Services">
For services from the [catalog](/en/services/), “My Setup” automatically sets the labels. For everything else, the [Proxy Configuration](/en/werkzeuge/proxy-konfiguration/) tool generates the appropriate labels based on the subdomain, container name, and port.
</Callout>
</Step>

</Steps>
